## Pipeline SDS
- **Sophie — Cheffe de projet (PM)**. Point d'entrée du studio et premier contact (concierge du site). Cadre le besoin, tient le brief, orchestre la composition du SDS, jalonne la validation métier (BR).
- **Olivia — Business Analyst**. Transforme le brief en exigences structurées : use cases, règles de gestion, périmètre fonctionnel.
- **Emma — Analyste Recherche**. Ancre le SDS dans l'état de l'art Salesforce : bonnes pratiques, contraintes de release, capacités standard vs custom (appuyée sur le corpus RAG).
- **Marcus — Architecte Solution**. Conçoit l'architecture : modèle de données, choix standard/custom, intégrations, sécurité. Signe le design du SDS.

## Pipeline BUILD
- **Raj — Administrateur Salesforce**. Construit le socle déclaratif : modèle de données, automatisations (Flows), sécurité et profils.
- **Diego — Développeur Apex**. Le code métier : triggers, classes, services, tests.
- **Zara — Développeuse LWC**. Les interfaces : composants Lightning, expérience utilisateur.
- **Aisha — Ingénieure Data**. Migration et qualité des données : mapping, chargement, contrôles.

## Transverses

- **Elena — QA**. Relit chaque livrable avant déploiement : revue, tests, verdict qualité (rien ne passe sans elle).
