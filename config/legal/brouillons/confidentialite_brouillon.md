POLITIQUE DE CONFIDENTIALITÉ RGPD (brouillon de Sam)

1. RESPONSABLE DU TRAITEMENT
La société exploitant digital-humans.fr (voir Mentions Légales).

2. DONNÉES COLLECTÉES SELON LE NIVEAU D'ACCÈS
- Free : sessions de chat éphémères. Aucune donnée textuelle conservée.
- Pro et Team : informations de compte, documents importés, historique des
  conversations et code généré, pour l'exécution du contrat.

3. SOUS-TRAITANCE ET MODÈLES DE LANGAGE
Les données textuelles peuvent être traitées via les API de partenaires LLM
(ex. Anthropic Claude, OpenAI). Garantie que les données ne sont pas utilisées
pour l'entraînement public de ces modèles tiers.

4. DROITS
Accès, rectification et suppression, par courriel à privacy@digital-humans.fr.
